# Relic — Context

Relic is a privacy-first Chrome extension (Manifest V3, v3.1.6, TypeScript/React 19/Tailwind 4, built with Vite) that analyzes SEC/EDGAR filings entirely on-device. Nothing leaves the user's machine: no telemetry, no cloud APIs, no accounts. The only network egress is user-initiated GETs to `*.sec.gov` (fetching the prior year's filing for comparison), enforced at the platform level by a CSP `connect-src` locked to sec.gov and verified by a build-time gate script.

**What it does.** On any EDGAR filing (10-K, 10-Q, 8-K, 20-F, S-1, proxy), a side panel offers four tabs: **Analyst** (Bullish/Bearish/Mixed snapshot, takeaways, revenue/margin/cash-flow/risk insights, bull-vs-bear case, 1–5 scores), **Summary** (per-section plain-English summaries), **Sentiment** (sentence-level FinBERT tone scores in the side panel), and **Redline** (one-click year-over-year redline against the prior comparable filing, with cosmetic rewordings filtered out via embedding similarity). Language flags (hedging, uncertainty, litigious, negative) are underlined in-place on the filing. Jump-to-source highlighting links insights back to the page. Results export to a selectable-text PDF. Non-EDGAR financial pages get on-demand analysis via activeTab.

**Architecture.** A content script ingests the page into a normalized DocumentModel with a positionMap (text→DOM ranges, O(log n)); all on-page highlighting uses the CSS Custom Highlight API (no DOM mutation, so EDGAR's XBRL viewer survives). An MV3 service worker routes messages and runs a rate-limited (≤8 req/s) EDGAR fetch queue. An offscreen document hosts two ONNX Runtime Web workers — FinBERT (~107 MB int8) for sentiment and mxbai-embed-xsmall (~24 MB) for extractive summaries and redline matching — with WebGPU→WASM fallback and idle unload. Model weights are bundled at build time (`allowRemoteModels=false`); no runtime model downloads. Generative text uses Chrome's built-in AI (Gemini Nano via Prompt/Summarizer APIs) when available, falling back to a deterministic/extractive tier otherwise. Every LM output passes hallucination guards: quoted evidence must be found verbatim in the filing or it's dropped, cited figures must exist in the source, and investment-advice phrasing is scrubbed.

**Current state.** Feature-complete and polished; 536 passing unit tests (7 skipped); prepared for Chrome Web Store submission (`PRIVACY.md`, `STORE_LISTING.md`, `CWS_SUBMISSION.md` present — the privacy policy still needs public hosting before submit). The earlier pre-launch permission/CSP gaps are resolved: no `web_accessible_resources` are declared at all, the third-party financial sites are `optional_host_permissions` (never granted at install, requested per-site on demand), and the CSP is `default-src 'none'` with `connect-src` locked to `*.sec.gov`. Differentiators: provable zero egress, evidence-verified output, and the in-place YoY redline.
